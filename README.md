# KU Tech website

The website for KU Tech, LLC: managed IT, cybersecurity, cloud solutions and more, with 24/7/365 support.

Live site: https://kutech.it

## How it's hosted

This repository is published with **GitHub Pages**. Every change pushed to the `main` branch goes live automatically within a minute or two.

- `index.html` is the home page. Other pages: `services.html`, `about.html`, `contact.html`, and one page per service.
- `styles.css` and `site.js` hold the design and scripts.
- `sitemap.xml` and `robots.txt` help search engines find every page.
- `CNAME` tells GitHub Pages to serve the site at kutech.it.

## Contact form

The contact form sends messages through [Web3Forms](https://web3forms.com). Paste your access key into `site.js` where it says `YOUR_WEB3FORMS_ACCESS_KEY`, then commit the change.

## Editing

Small text edits can be made right on GitHub: open a file, click the pencil icon, edit and choose **Commit changes**.
